# 🌱 Цифровой Сад — Management Core

## Что это

Центральное ядро персональной экосистемы. Это **не** очередной чат-бот и **не** ещё один фреймворк.
Это **блок менеджмента**, который:

1. **Помнит** — долговременная память между сессиями, фактами, сущностями
2. **Понимает** — семантический роутинг (определяет что ты хочешь)
3. **Координирует** — разбивает задачи и направляет исполнителям
4. **Не делает работу сам** — вся работа уходит на «аутсорс» через API/MCP

## Быстрый старт

### 1. Установка

```bash
cd digital_garden
pip install -r requirements.txt
```

### 2. Настройка

Отредактируй `config/garden.yaml`:
- Укажи ngrok URL для Ollama (из Colab)
- Укажи порт AI Super Router (если запущен)
- Остальные исполнители — по мере развёртывания

### 3. Запуск

```bash
# Интерактивный чат
python main.py chat

# API-сервер (для подключения других сервисов)
python main.py serve

# Статус системы
python main.py status
```

### 4. Команды в чате

| Команда | Описание |
|---------|----------|
| `/status` | Статус всех компонентов |
| `/memory` | Что система помнит |
| `/history` | История задач |
| `/paradigm кибернетика` | Сменить парадигмальную линзу |
| `/fact Я живу в Петербурге` | Добавить факт в память |
| `/quit` | Выход |

## Как это работает

### Пример: "Найди вакансии дизайнера"

1. **Семантический роутер** → Intent: `SEARCH`
2. **Память** → Факты: "живёт в Петербурге", "рисует", "был дизайнером памятников"
3. **Оркестратор** → Исполнитель: `browser_use` (приоритет для поиска)
4. **Browser Use** → Парсит hh.ru, avito, telegram-каналы
5. **Результат** → Сохраняется в память + возвращается тебе

### Пример: "Напиши отклик на эту вакансию тёплым стилем"

1. **Роутер** → Intent: `COMMUNICATE`
2. **Память** → Стиль: "тёплый, индивидуальный, без ощущения бота"
3. **Оркестратор** → Исполнитель: `llm_router`
4. **AI Super Router** → Генерирует текст с учётом контекста из памяти
5. **Результат** → Черновик отклика

## Подключение нового исполнителя

Через конфиг (`config/garden.yaml`):

```yaml
executors:
  my_new_service:
    type: "mcp_server"
    name: "Мой Сервис"
    endpoint: "http://localhost:9999/mcp"
    priority: 3
    capabilities:
      - search
      - automate
```

Или программно:

```python
from core.manager import Executor, Intent

core.register_executor(Executor(
    id="my_service",
    name="Мой Сервис",
    type="mcp_server",
    capabilities=[Intent.SEARCH, Intent.AUTOMATE],
    endpoint="http://localhost:9999/mcp",
))
```

## Связь с AI Super Router

Management Core использует AI Super Router как основной LLM-бэкенд:

```
Management Core (порт 8080) → AI Super Router (порт 8000) → 22 провайдера
```

Запусти оба:
```bash
# Терминал 1: AI Super Router
cd ai_super_router && python main.py serve

# Терминал 2: Management Core
cd digital_garden && python main.py serve
```
