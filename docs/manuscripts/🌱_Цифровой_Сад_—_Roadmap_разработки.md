## 🏗️ Архитектурные принципы

1. **Всё через API** — никакой монолитной логики, каждый модуль = отдельный сервис
2. **MCP как стандарт** — новые инструменты подключаются через Model Context Protocol
3. **Память — центр** — каждое действие обогащает граф знаний
4. **Бесплатно** — всё работает на Oracle Cloud Free + Google Colab + бесплатные API
5. **Минимум работы для человека** — система должна быть автономной насколько возможно
