## 1. Зачем

Текущий канон (H = 1 − stress по 4 ratio) и пайплайн:

- хорошо **сворачивают** часть внешних метрик в число;
- **не** порождают действие, если очередь пуста и «всё в норме»;
- при достижении таргетов агент логически **засыпает** (STALL) — это не автономия.

Гомеостаз — **главный** контур агента: внешние датчики → внутреннее состояние → **непрерывный** сигнал «что делать сейчас». Остальное (Γ, Φ, LLM) — ограничения и исполнители, не источник импульса.

---

## 2. Принципы (жёстко)

1. **Внешнее → внутреннее.** Бюджет, очередь, uptime, дедлайны, споры — только через переменные состояния / давления. Не «отдельная команда мимо гомеостаза» (исключение: emergency-override владельца, уже в `01`).
2. **Импульс всегда ненулевой** (пока агент включён). Равновесие ≠ сон. В зоне таргетов работают **maintenance / exploration** драйвы (pipeline, skill, review), иначе это оптимизатор «дошёл до цели и выключился».
3. **Много переменных, одно решение.** Панель здоровья (архив FREELANCER), не одна ось. Приоритет — по величине и типу давления.
4. **Два режима отклонения.** *Deficit* (мало денег, пустой pipeline) и *overload* (перегруз) — разные классы действий.
5. **Cold-start vs жизнь.** Стартовые веса/пороги — из конфига (в пробе для отладки — явный default). Дальше — оптимизация; в MVP-пробе — defaults + лог.
6. **H и Λ не выкидывать.** H — сводка комфорта; Λ — диагноз петель. **Действие** даёт слой **Impulse** из давлений.

---

## 3. Модель (кратко)

Переменные: cash, runway, reputation, workload (band), pipeline, quality, skill.

Давление: deficit / overload / **baseline (anti-sleep)**.

`ImpulseSet = propose(pressures)` — **всегда** ≥ 1 при agent.enabled.

В равновесии: SCOUT_LIGHT, LEARN, AUDIT_RISK, RELATE (ротация).

---

## 4. Симуляция

`python -m` / `srs/homeostasis_v2/simulate.py` — сценарии crisis / equilibrium / overload / recovery.

Критерий: equilibrium **не** idle; crisis → EARN; overload → THROTTLE.
