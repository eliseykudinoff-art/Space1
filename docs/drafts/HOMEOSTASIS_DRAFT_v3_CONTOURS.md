## 1. Верное разделение (канон замысла)

| Контур | Роль | Делает | Не делает |
|--------|------|--------|-----------|
| **Гормоны** | Живой **пульс** реакции на события | stress↑ / go↑ на токены out, reject, tech warning, тупик, **скука**; phasic на прогресс/снятие тупика | Не считает Φ, не выбирает LLM, не ведёт бюджет, не ставит job-types |
| **Гомеостаз** | **Мотор** регуляции | **Быстро:** реакция на пульс (urge, обрыв петли, тик ревизии). **Медленно (аллостаз):** сдвиг режима/чувствительности наперёд | Не подменяет бухгалтерию и Γ |
| **Метрики / ядро** (17 факторов, Φ, Ψ, Υ, Q, Γ, C_t, …) | Зрение и ограничения | Цифры для «какую LLM, почём, можно ли» | Не заменяют ощущение «жжёт / тянет» |
| **Ревизия (B)** | Ясность | По URGE и снимку состояния — *где* перекос | Не сам импульс «надо» |
| **Действие (C)** | Исполнение | Γ, 𝒟, sandbox, заказ, specialist | Не источник жизни агента в покое |

**Инварианты:**

1. Гормоны **реагируют** на метрики и события; **не заведуют** ими.
2. Гомеостаз = мотор на **двух скоростях** (fast + allostatic slow).
3. Без stress — риск **бесконечного продолжения** (LLM-петли); скука = stress (сидеть нельзя).
4. Конкретные действия **не** выводятся менюшкой из гормонов (ошибка draft v1 / homeostasis_v2).

```text
События (лимиты, reject, warnings, тупик, idle, успех)
        │
        ▼
 [ГОРМОНЫ: пульс]  stress / go
        │
        ▼
 [ГОМЕОСТАЗ: мотор]
    fast  → URGE, обрыв бесплодного цикла
    slow  → аллостаз режима
        │
        ▼
 [РЕВИЗИЯ] → ясность
        │
        ▼
 [МЕТРИКИ + Γ + 𝒟 + LLM] → шаг
```

## 2. Что не готово (математика)

- Полные формулы phasic/tonic stress и go.
- Замкнутый RPE от изменения drive — набросок, не канон.
- Вектор осей состояния для мотора.
- Закон скуки в числах.
- Связь load с частотой ревизии и soft-политикой (без подмены Γ).

---

## 3. Техдолг (критично)

| Факт | Следствие |
|------|-----------|
| Постоянное обновление **гормонального фона** по событиям **не реализовано** | Нет живого пульса в runtime |
| Драйвер цикла = **очередь задач**; пусто → STALL | Нет мотора «сидеть нельзя» |
| H / PID / UtilityModulator / SystemMonitor — осколки | Ложное «гомеостаз уже есть» |
| `srs/homeostasis_v2` (deficit→EARN) | **Не** канон |
| Архивный dopamine/cortisol | Не восстанавливать 1:1 |

**Оценка:** встроить пульс + двухскоростной мотор ≈ **существенная перепись** связки оркестратора, не точечный патч.

Ориентир порядка: контракт событий→гормоны → тик гомеостаза без `pop_next_task` → URGE→ревизия→метрики/Γ/LLM → убрать STALL-как-норму → полная математика позже.
