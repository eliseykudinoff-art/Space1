## Финальные cold-start (после симов)

Цель idle: S_eq ∈ [0.15, 0.30], не потолок.

| Параметр | Значение |
|----------|----------|
| b (boredom) | 0.03–0.035 |
| λ_S | 0.12 |
| λ_G | 0.18 |
| τ_0 | 10 |
| α_S / α_D / α_def | 0.50 / 0.45 / 0.30 |
| θ_rev | 0.28 |
| θ_break | 0.75 |
| θ_urgent | 0.45 |
| S_def_max | 0.50 |
| c_def | 0.15 |

S_eq ≈ b/(1−e^(−λ_S)) ≈ 0.27–0.31.

Доп. события (к EVENTS_v0): TOOL.FAIL, MEMORY.GAP, DEF.ITEM_ADDED, DEF.ITEM_DONE, DEF.ITEM_OVERDUE.

Режимы ревизии: **urgent** (высокий S / overdue backlog) vs **prospective** (низкий S, живой G).
