## 1. Зачем этот модуль

Агент должен **жить**, а не только отвечать на задачу из очереди.

- Без внутреннего напряжения LLM-контур склонен **продолжать бесконечно** (тупики, повторы).
- При «зелёных» метриках и пустой биржевой очереди текущий пайплайн уходит в **STALL** — это не автономия.
- Чистый RL к внешним «плюшкам» ломает внутренний баланс (безопасность, регламенты, репутация, обучение).

**Гомеостаз** — главная фича: мотор, который держит агента в движении и в балансе.
**Гормоны** — живой пульс реакций на всё, что происходит.
Остальная математика (Φ, Ψ, Γ, 17 факторов, цены LLM…) — зрение и ограничения для **ясных** решений после ревизии.

## 2. Разделение контуров (канон замысла)

```text
События исполнения и среды
        │
        ▼
┌───────────────────────────────┐
│  ГОРМОНЫ — пульс              │
│  stress / go                  │
│  реакция, не бухгалтерия      │
└───────────────┬───────────────┘
                │
                ▼
┌───────────────────────────────┐
│  ГОМЕОСТАЗ — мотор            │
│  fast:  urge, обрыв петли     │
│  slow:  аллостаз режима       │
└───────────────┬───────────────┘
                │ URGE
                ▼
┌───────────────────────────────┐
│  РЕВИЗИЯ — ясность            │
│  где перекос в состоянии      │
└───────────────┬───────────────┘
                │
                ▼
┌───────────────────────────────┐
│  МЕТРИКИ + Γ + 𝒟 + LLM        │
│  какую модель, почём, можно ли│
└───────────────────────────────┘
```

### 2.1 Гормоны (пульс)

| | |
|--|--|
| **Роль** | Внутреннее реагирование на события |
| **Выход** | Уровни / спайки **stress** и **go** |
| **Примеры входов** | Кончились токены; отказ заказа; technical warning; тупик шагов; долгий idle (**скука = stress**); прогресс / снятие тупика |
| **Не делает** | Не считает Φ, не выбирает LLM, не ведёт бюджет, не назначает job-types |

Гормоны **не заведуют** деньгами и статистикой — они **на них реагируют**.

### 2.2 Гомеостаз (мотор)

| Темп | Поведение |
|------|-----------|
| **Fast** | Мгновенная реакция на пульс: URGE, ревизия, обрыв бесплодной LLM-петли |
| **Slow (аллостаз)** | По истории stress/go — сдвиг чувствительности и режима **наперёд** |

### 2.3 Ревизия

Вход: URGE + снимок состояния. Выход: ясность — *где* перекос (ещё не план на бирже).

### 2.4 Метрики и действие

17 факторов, Φ, Ψ, Υ, Q, Ω, Γ, C_t, H, Λ, цены моделей — **как** и **можно ли**. Γ_hard — всегда veto.

---

## 3. Инварианты

1. Импульс жизни не зависит только от `scheduler.pop_next_task`.
2. Без stress нет тормоза бесконечного продолжения.
3. Скука — stress; равновесие метрик ≠ sleep.
4. Гормоны реагируют; метрики описывают; мотор связывает; ревизия проясняет; действие исполняет.
5. Конкретные работы не являются выходом гормонального контура.

## 5. События → пульс

Нормативный словарь: **`HOMEOSTASIS_EVENTS_v0.md`**.

| Класс | Эффект |
|-------|--------|
| Лимиты ресурсов | stress↑ |
| Отказы / warnings | stress↑ |
| Тупик исполнения | stress↑ |
| Idle / скука | stress↑ |
| Прогресс / успех | go↑; stress может↓ |

---

## 6. Техдолг

Нет постоянного гормонального фона; цикл от очереди → STALL; встраивание ≈ существенная перепись оркестратора.

Порядок: контракт событий → каркас формул → точки врезки → тик без `pop_next_task` → URGE→ревизия→метрики → калибровка.

---

## 7. OWNER_DIRECT

Ортогонален контуру; emergency — override. Оба могут порождать события для пульса.
