# Pre-LLM upper stack

## Канон действия (не путать)

1. **Гомеостаз** (S, G, urge, mode, revision_needed) — внутреннее состояние и давление действовать.
2. **Сигнал к действию** собирается в **промпт к LLM** (синтез контекста из life + rules + mission + метрик).
3. **LLM делает** — поиск работы, разбор заказа, исполнение и т.д.

**Нет** отдельных seek_job / self_task / параллельных executive-лупов «вместо LLM».

Входящая заявка в очереди — опциональное внешнее событие, не главный двигатель.

## Имена

| Символ | Смысл |
|--------|--------|
| **U** | полезность (decision / φ) — единственное U |
| **urge** | давление мотора гомеостаза (не U) |
| **H** | wellbeing для порогов cascade |
| **S, G** | stress / reward |

## Idle

Пустая очередь → life tick (`IDLE_TICK`) + snapshot. Это **не** сон и **не** создание фейковых задач.
Дальше по канону snapshot life должен входить в синтез промпта; исполнение — через LLM.

## Stage I–VII при уже взятой единице работы

Отбор (Γ, φ̂, decision) до LLM. Не подмена LLM отдельным контуром поиска.
