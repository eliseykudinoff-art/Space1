## Что такое Space1 (коротко)

Один экономический агент с явным математическим ядром (не LLM с системным промптом — оркестратор, вызывающий LLM как один из инструментов), плюс личный ассистент владельца поверх того же пайплайна. По умолчанию агент доделывает текущую работу, затем берёт задачу владельца; режим «брось всё» — только по явному emergency-override. Полная концепция — `01_CONCEPT.md`.

## Открытые вопросы, не решённые явочным порядком (сводка по всему корпусу)

Ничего из перечисленного не блокирует текущую реализацию (текущие значения по умолчанию заданы и обоснованы) — это решения, требующие суждения владельца системы, не технического суждения:

1. **Трактовать ли минимальный порог $\Upsilon$ как $\Gamma_{hard}$-подобное ограничение**, а не только вес в $U$ — поднято в `02`, усилено внешними данными в `06` §II.3 (JSS и риск блокировки аккаунта связаны сильнее, чем казалось изначально).
2. Все параметры со статусом **[О]** в реестрах параметров каждого документа — не открытые вопросы в том же смысле (это ожидаемая, не блокирующая неопределённость), но их сводная приоритизация — `07_CALIBRATION_AND_VALIDATION.md` Часть V.

**Закрыто:**
- Vision А/Б-развилка (кто клиент системы) — единый пайплайн, источник задачи как атрибут.
- **Payment-terms / OWNER_DIRECT** (`01_CONCEPT.md` §I.3–I.4, 2026-08-01) — по умолчанию агент доделывает текущую работу, затем берёт задачу владельца; emergency-override («брось всё») только по явному приказу. Новых параметров не вводится; используются существующие Mission/SURVIVAL, Γ и HITL. `source` не даёт права обходить Γ.
