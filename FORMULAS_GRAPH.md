# 🔗 ПОЛНЫЙ ГРАФ ВЗАИМОСВЯЗЕЙ ФОРМУЛ

## Обозначения
```
[A] → [B]    : A используется в B (B зависит от A)
[A] ← [B]    : B используется в A (A зависит от B)
[A] ↔ [B]    : Циклическая зависимость
[A] !!!      : Критическая ошибка (использование до определения)
[A] ???      : Неопределённая переменная
```
